Search the vault for notes matching the query and return a summary.

Usage: /search <query>

1. Search all markdown files in this vault for the query string (case-insensitive).
2. Return the top 10 most relevant matches with their file paths and the matching excerpt.
3. Summarize the results: what themes emerge, which notes are most directly relevant, and suggest 2-3 related wikilinks the user might want to follow.
