# Plugins

← [[help/index|Help]]

## Community

| Plugin | Purpose |
|--------|---------|
| Calendar | Sidebar calendar widget for opening or creating daily notes |
| Kanban | Board view for `boards/` — each card links to a note |
| Iconic | Custom icons for files and folders in the file explorer |

## Core

| Plugin | Purpose |
|--------|---------|
| Daily Notes | Creates and opens today's note in `notes/daily/` |
| Templates | Inserts a template into the current note |
| Bases | Live query views — powers `bases/daily.base` and `bases/meetings.base` |
| Canvas | Freeform visual boards stored in `canvases/` |
| Graph | Visual map of note connections |
| Tag Pane | Sidebar view of all tags across the vault |
| Bookmarks | Pinned notes and searches |
| Outline | Sidebar heading navigator |
| Slash Commands | Trigger commands inline with `/` |
